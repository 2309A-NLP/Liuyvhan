# Agent-01 记账本 — 优化总结

## 一、架构优化

### 1.1 整体架构

Agent-01 记账本采用 **FastAPI + NLP意图解析 + MySQL 数据层 + Web UI** 的四层架构，核心流水线为：

```
用户输入 → NLP意图解析 → 对话状态管理 → 意图路由 → MySQL CRUD → 确认反馈 → Web UI展示
```

| 架构维度 | 当前方案 | 优势 |
|----------|---------|------|
| Web框架 | FastAPI | 高性能异步框架，自动生成OpenAPI文档 |
| 存储层 | MySQL (pymysql) | 成熟的关系型数据库，事务支持好 |
| NLP方式 | 正则表达式+规则引擎 | 轻量级，无需GPU，推理速度<10ms |
| 前端 | 自定义HTML静态页 | 轻量化，无前端框架依赖 |
| 部署 | 单进程uvicorn | 部署简单，零配置 |

### 1.2 核心模块

- **agent_parser.py**: NLP意图解析，支持日期/成员/金额/类别四维提取
- **agent.py**: 对话状态机，5种状态转换管理
- **database.py**: MySQL CRUD，7种查询方式
- **config.py**: 智能检测Windows/WSL MySQL连接

## 二、工程优化

### 2.1 NLP 解析引擎

| 特性 | 说明 |
|------|------|
| 日期提取 | 支持"今天/昨天/前天/x月x日/xxxx年x月x日"等多种格式 |
| 成员识别 | 3个默认成员 + 8组别名映射（老公→爸爸等） |
| 金额提取 | 6种正则模式覆盖，支持"花了XX元/交了XX/XX块"等 |
| 类别归类 | 15个支出类目 + 5个收入类目，按关键词长度优先匹配 |
| 事项提取 | 13步清洗流程，自动去除量词/动词/日期/金额残留 |

### 2.2 对话状态机

5种状态实现了完整的交互流程：

1. **IDLE**: 空闲状态，接收任意输入
2. **PENDING_INFO**: 待补充信息状态，自动追问缺失字段
3. **PENDING_CONFIRM_ADD/DELETE/UPDATE**: 待确认操作，防止误操作

### 2.3 MySQL 查询优化

7种查询覆盖所有记账场景：
- 单品关键词查询（如"三体什么时候买的"）
- 成员月度汇总（如"女儿本月花了多少"）
- 分类统计（如"买书花了多少钱"）
- 月度完整明细（含分类汇总）
- 条件删除匹配
- 记录修改
- ID查询

## 三、数据优化

### 3.1 类别体系

15个支出类目 + 5个收入类目，共覆盖 **~120个关键词**：
- **精确匹配优先**: 长关键词优先于短关键词
- **别名兼容**: 老公/老婆/孩子自动映射
- **多级分类**: 同义词扩展（如"奶茶"→餐饮）

### 3.2 测试数据

共计 **17条NLP解析测试用例**，覆盖：
- 正常语句: "今天女儿买了双登山鞋499元"
- 简略语句: "三体花了50"
- 缺失字段: "今天买了本书"（缺成员+金额）
- 别名输入: "老公今天iPhone花了8000"
- 复杂语句: "给女儿交了50话费"

## 四、性能优化

### 4.1 模块级延迟

| 模块 | 延迟 | 说明 |
|------|------|------|
| NLP解析 | <5ms | 纯正则，无模型推理 |
| 状态管理 | <1ms | 简单状态机 |
| 数据库查询 | 10-50ms | 本地MySQL |
| API响应 | 15-60ms | 含全链路 |

### 4.2 JSON 序列化修复

修复了 `date` 对象无法直接JSON序列化的bug：在返回前端前将 `date` 对象转为 `str`，避免FastAPI的JSONResponse报错。

### 4.3 WSL兼容

智能检测运行环境（Windows/WSL），自动获取正确的MySQL主机地址（WSL网关IP vs 127.0.0.1）。

## 五、可维护性优化

### 5.1 代码结构

```
├── main.py          # FastAPI入口，路由定义
├── agent.py         # 对话状态机+业务逻辑
├── agent_parser.py  # NLP意图解析引擎
├── database.py      # MySQL数据层
├── config.py        # 环境配置（MySQL/端口）
├── test_fix.py      # 测试脚本
└── ui/index.html    # Web UI前端
```

### 5.2 扩展建议

1. **LLM 增强**: 将正则NLP替换为LLM解析，可处理更复杂的语义
2. **持久化会话**: 当前状态机在内存中，重启会丢失对话上下文
3. **多用户支持**: 当前是单用户系统，可扩展用户认证
4. **数据可视化**: 增加图表展示月度/季度收支趋势
5. **账单导入**: 支持支付宝/微信账单CSV导入
