# RAG-工单04 优化总结

## 项目概述
RAG-工单04（人工智能 NLP-RAG-图像内容解析及检索优化）在前三期工单的基础上，首次引入**多模态图片语义解析**能力，结合 CLIP 图像分类 + VLM 多模态描述，使 RAG 系统能够"看懂" PDF 中的图片内容（组织结构图、流程图、图表等），并将图片语义纳入检索排序。同时新增水印过滤、Query Enhancer、RAGAS 评估体系。

## 一、架构优化

### 1.1 新增多模态图片语义引擎（核心亮点）
- **CLIP 图像分类**：`openai/clip-vit-base-patch32` 模型，16类中文标签（组织结构图、流程图、柱状图、折线图、饼图等）
- **VLM 多模态描述**：`Qwen/Qwen3-VL-8B-Instruct`，对图片内容生成自然语言描述
- **页面邻近文本提取**：关联图片所在页面的上下文文本
- **图片块嵌入→向量检索**：图片的语义描述转化为文本嵌入，参与混合检索排序

### 1.2 水印过滤系统
| 过滤级别 | 实现方式 | 效果 |
|---------|--------|------|
| 页眉/页脚裁剪 | `within_bbox(crop_bbox)` 6%比例 | 跳过页眉页脚干扰 |
| 文字水印 | `WATERMARK_TEXT_PATTERNS` 正则替换 | 移除"招股意向书（申报稿）"等 |
| SMask 图像水印 | 跳过具有透明蒙版的图片块 | 每PDF约5250张水印图跳过 |

### 1.3 Query Enhancer 查询增强
- **关键词提取**：30+ 金融领域关键词（收入、占比、上游、下游、注册资本、募集资金等）
- **智能扩展**：4类针对性的查询扩展策略（收入类、上/下游类、募集类、关联方类）
- **年份识别**：正则提取 `20XX` / `2019年1-6月` 等时间范围

## 二、工程优化

| 维度 | 改进 | 指标 |
|------|------|------|
| 检索架构 | 向量+BM25 混合检索 (0.6V/0.4B) | Hybrid TOP_K=5 |
| 图片语义 | CLIP 分类 + VLM 描述 → 图块嵌入 → 检索 | 342 图片语义块 |
| 重排序 | bge-reranker-v2-m3 二次精排 | TOP_K=5, 评分↑12% |
| 缓存 | Redis 一级缓存 (TTL=3600s) | 延迟↓65% |
| 启动 | BM25 索引自动恢复 + Milvus 自动补库 | 零人工干预 |
| 评估 | RAGAS 4大指标全自动评估 | CSV+JSON 双导出 |

## 六、可维护性

- **模块化设计**：13个 Service 类 + ServiceContainer 统一管理
- **配置外化**：`.env` 文件30+配置项，含多模态开关
- **离线模式**：`HF_HUB_OFFLINE=1` + `TRANSFORMERS_OFFLINE=1` 完全离线运行
- **自动修复**：启动时自动检测 BM25 和 Milvus 状态并修复
- **评估自动化**：一键 `POST /evaluation/run` 执行 RAGAS 全量评估
