## 4. 批量自动化测试

编写一个简单的批量测试脚本：

```python
"""test_deployment.py - 部署验证测试脚本"""
import requests
import json
import sys

BASE_URL = "http://localhost:8000"
PASS = 0
FAIL = 0

def test(name, condition, detail=""):
    global PASS, FAIL
    if condition:
        PASS += 1
        print(f"  [PASS] {name}")
    else:
        FAIL += 1
        print(f"  [FAIL] {name} - {detail}")

# 1. 健康检查
print("=" * 50)
print("1. 服务健康检查")
print("=" * 50)
try:
    r = requests.get(f"{BASE_URL}/api/v1/health", timeout=10)
    test("健康接口返回 200", r.status_code == 200, f"状态码: {r.status_code}")
    data = r.json()
    test("状态为 ok", data.get("status") == "ok", f"status: {data.get('status')}")
except Exception as e:
    test("健康接口可访问", False, str(e))

# 2. 根路径
print("\n" + "=" * 50)
print("2. 根路径验证")
print("=" * 50)
try:
    r = requests.get(f"{BASE_URL}/", timeout=10)
    test("根路径返回 200", r.status_code == 200)
    test("包含 docs 字段", "/docs" in r.text)
except Exception as e:
    test("根路径可访问", False, str(e))

# 3. RAG 问答
print("\n" + "=" * 50)
print("3. RAG 问答测试")
print("=" * 50)
try:
    r = requests.post(f"{BASE_URL}/api/v1/chat/rag",
        json={"question": "测试问题", "session_id": "deploy-test"},
        timeout=60)
    test("RAG 接口返回 200", r.status_code == 200)
    data = r.json()
    test("返回包含 answer", "answer" in data)
    test("answer 非空", bool(data.get("answer")))
except Exception as e:
    test("RAG 接口可访问", False, str(e))

# 4. 总结
print("\n" + "=" * 50)
print(f"测试结果: {PASS} 通过, {FAIL} 失败, 共 {PASS + FAIL} 项")
print("=" * 50)

if FAIL > 0:
    sys.exit(1)
```

**运行方式**：

```bash
# 在宿主机上运行
python3 test_deployment.py
```

## 5. 容器启动测试

### 5.1 docker-compose 启动

```bash
# 停止所有容器
docker compose down

# 重新启动
docker compose up -d

# 检查所有容器状态
docker compose ps
```

**验证标准**：
- 所有服务的 STATUS 列为 `Up`（可通过 `docker compose ps` 确认）
- 所有服务的 STATUS 列显示 `(healthy)` 表示健康检查通过
- 无 `Exited` 或 `Restarting` 状态

### 5.2 docker run 单独启动

```bash
# 确保 Milvus 和 Redis 在运行
docker compose up -d milvus redis

# 使用 docker run 启动应用
docker run -d \
  --name rag-app-standalone \
  -p 8000:8000 \
  -e MILVUS_URI="http://milvus:19530" \
  -e REDIS_URL="redis://redis:6379/0" \
  -e LLM_API_KEY="sk-your-key" \
  -e LLM_BASE_URL="https://api.siliconflow.cn/v1" \
  -e LLM_MODEL="deepseek-ai/DeepSeek-V4-Flash" \
  -v rag-data:/app/data \
  --network rag-network \
  rag-financial-qa:latest

# 验证启动成功
docker ps | grep rag-app-standalone
curl http://localhost:8000/api/v1/health

# 测试完成后清理
docker stop rag-app-standalone
docker rm rag-app-standalone
```
