# 3分钟答辩稿

各位老师好，我的项目是基于 `招股说明书1.pdf` 构建一个 PDF 问答系统，核心目标是让系统能够先从文档中检索证据，再结合大模型生成准确回答，并且能和纯 LLM 的回答效果做对比评估。

在实现上，我做了几项关键工作。第一，完成了 PDF 解析、切块、向量化和索引构建，支持 `RAG` 和 `纯LLM` 两条独立问答链路。第二，检索层采用了向量检索加 BM25 的混合检索方式，并接入中文分词和重排序模型，提升了中文场景下的召回和排序效果。第三，针对注册资本、法定代表人、募集资金、上游下游、收入占比这类结构化问题，我增加了字段式直答和表格数值优先抽取，尽量让答案贴近原文。

在评估结果上，我整理了 10 道验收题。人工核验结果是 9 题正确、1 题部分正确；自动评估中，RAGAS 的 `answer_relevancy` 为 `0.7740`，`context_precision` 为 `0.9171`，`context_recall` 为 `1.0000`，`faithfulness` 为 `0.4833`。对比纯 LLM 后可以看到，RAG 在数值题、字段题和标准名称题上明显更稳定，纯 LLM 则更容易出现幻觉和扩写错误。

同时，系统也暴露出一个性能问题。目前 RAG 链路的平均耗时大约是 `16.186` 秒，虽然准确性更高，但还没有满足工单里 `3 秒内` 的响应要求，所以后续还需要继续优化检索、重排序和生成链路的整体耗时。

总体来说，这个项目已经完成了从文档解析、混合检索、答案生成到评估对比的完整闭环，具备较好的可交付性，也为后续进一步优化性能和答案稳定性打下了基础。谢谢老师。
